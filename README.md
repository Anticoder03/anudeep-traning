# Python Practice Projects

This repository contains beginner-friendly Python exercises, a small PyQt6 to-do list application, and a Django practice app. It is designed to help learners practice core Python concepts such as variables, operators, loops, functions, lists, file handling, and basic GUI development.

## Project Overview

The workspace includes:
- Simple Python practice scripts for fundamental programming concepts
- A small to-do list application built with PyQt6
- A Django-based practice app in the my-django-app folder
- Example programs for assignments and daily learning

## Files Included

- main.py — A to-do list application with add, edit, remove, and clear actions
- task-1.py and task-2.py — Practice scripts and assignment-style examples
- functions.py — Function-related exercises
- loops.py — Loop-based practice programs
- list_operations.py — List manipulation examples
- file_operations.py — File handling exercises
- Q1.py and nimmaxsum.py — Additional Python practice files
- student.txt — Sample data file used in some exercises
- my-django-app/ — A small Django practice project

## Requirements

To run the GUI application, make sure you have Python installed and install PyQt6:

```bash
pip install PyQt6
```

To run the Django app, install the requirements:

```bash
pip install -r my-django-app/requirement.txt
```

## How to Run

Run the to-do list app:

```bash
python main.py
```

Run other Python exercises individually:

```bash
python task-1.py
python task-2.py
```

Run the Django app:

```bash
cd my-django-app
python manage.py runserver
```
